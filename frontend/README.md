# Sentinel — Frontend React

Interface React 19 + TypeScript du devoir Spring Security/JWT.

```bash
npm ci
npm run dev
```

L’application s’ouvre sur http://localhost:5173 et utilise l’API http://localhost:8081.

`npm run build` vérifie TypeScript et produit le dossier `dist`. `npm run lint` exécute ESLint.

Voir le [README principal](../README.md) pour lancer le backend, connaître les comptes de test, configurer l’API et utiliser les livrables.
